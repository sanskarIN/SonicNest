# SonicNest Roadmap

## v0.1.x — Foundation and recorder
- Stabilize cross-platform capture and codec fallback matrix.
- Exercise permission-denied, interruption, low-storage, and repeated pause/resume paths on physical devices.

## v0.2.x — Library and playback polish
- Persist generated waveform envelopes for imported media.
- Add richer desktop context menus and bulk actions.
- Expand media-session/lock-screen integration per platform.

## v0.3.x — Editor expansion
- Add selection handles directly on the waveform.
- Add undo/redo history UI and batch export presets.

## v0.4.x — Accessibility/performance
- Complete screen-reader and keyboard audit across all target platforms.
- Profile multi-hour recordings and libraries with thousands of entries.

## v1.0.0 — Stable release
- Zero known critical/high-priority reproducible bugs.
- Release checklist complete on Android, iOS, macOS, Windows, and Linux.
- Final store/release assets and signed packages prepared by the maintainer.
