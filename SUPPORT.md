# Support

**Gumroad Store:** https://ramsandesh.gumroad.com

For SonicNest help, include the app version, operating system, device model when relevant, selected recording format/preset, and a safe reproduction description.

When the issue involves runtime/storage/recorder/settings state, open **About → Diagnostics & QA** and review the privacy-safe report before sharing it. For a reproducible real-device or release-validation observation, **About → Manual QA evidence** can record fixed `Passed`/`Failed`/`Blocked`/`Not run` statuses and export a privacy-safe evidence bundle. Manual QA evidence deliberately has no free-form tester-note field.
